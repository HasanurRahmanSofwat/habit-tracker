Minimal Habit Tracker

Files:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

The tracker works as a normal local webpage.
For PWA installation/offline support, host these files together on HTTPS
(for example GitHub Pages).

Data:
- Habit data is stored locally in the browser.
- Settings > Data > Export backup downloads a JSON backup.
- Restore backup imports that file and replaces current tracker data.
